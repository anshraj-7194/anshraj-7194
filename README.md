## Nexment

**[Nexment](https://nexment.in)** is an open-source developer ecosystem — a suite of tools, APIs, packages, and platforms built to make software development faster and less painful.

- Open-source and built in public
- Focused on developer experience and productivity
- Includes CLI utilities, SDKs, APIs, and web applications
- Documentation-first approach
